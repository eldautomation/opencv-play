# Archive

These are old experiments from the start of the project: the first crosshair scripts and their images (`test_scripts/`), a config CRUD trial (`test.py`) and notes on test types (`readme-tests.py`). They are kept for reference only. They are not maintained and may no longer run against the current code, and they are not part of the `autocollimator` package or the test suite (pytest and packaging both exclude `archive/`).
